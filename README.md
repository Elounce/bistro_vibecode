# 🎡 Bistro 24 — Колесо выбора меню и REST API

Интерактивное веб-приложение «Колесо фортуны» для выбора блюд из ресторана **Bistro 24**, дополненное современным бэкендом на **.NET 10** и автоматизированным сбором актуального меню.

---

## 🌟 Основные возможности

### 1. Интерактивный фронтенд (`index.html`)
- **Умная выборка и категории**: быстрый выбор блюд по категориям (*Пицца, Роллы, Бургеры, Шаурма, Салаты, Горячее, Напитки*), а также специальный режим **«🎲 Случайные 10»** для идеальной читаемости колеса.
- **Подробная карточка победителя**: отображает реальную фотографию блюда, цену в рублях (`₽`), категорию, вес порции и состав ингредиентов.
- **Аудиоэффекты и тактильность**:
  - Натуральные механические щелчки трещотки при вращении секторов (на базе нативного **Web Audio API** без внешних mp3).
  - Физическое подёргивание стрелки в такт щелчкам.
  - Победный мажорный аккорд и полноэкранный салют конфетти.
  - Кнопка 🔊/🔇 с сохранением выбора пользователя в `localStorage`.
- **High-DPI / Retina**: чёткая отрисовка на любых экранах с учётом `devicePixelRatio`.
- **История выпадений**: блок «Выпадало ранее» с последними 5 результатами.
- **Ручной редактор**: скрытый под спойлер `<textarea>` для произвольного списка вариантов.

### 2. Скрипт обновления меню (`update-menu.ps1`)
- Загружает официальное меню Bistro 24 через API ресторана.
- Автоматически отфильтровывает непищевые записи (доставка, служебные пакеты) и очищает технические префиксы.
- Генерирует:
  - `menu.json` — структурированные объекты с фото, ценой, весом, составом и категорией.
  - `menu.js` — готовые константы `MENU_DATA` и `MENU_ITEMS` для браузера.
  - `menu.txt` — чистый текстовый список.

### 3. Бэкенд API (`BistroApi/`)
- Разработан на **ASP.NET Core 10 (.NET 10)**.
- **Entity Framework Core**:
  - Из коробки использует **SQLite** (`bistro.db`) для моментального локального запуска без настройки СУБД.
  - Поддерживает **PostgreSQL** (Npgsql) для продакшена.
  - Автоматический **Seeding**: при первом старте база данных автоматически заполняется 120 блюдами из `menu.json`.
- **REST Endpoints (`/api/menu`)**:
  - `GET /api/menu` — получение всех блюд (фильтрация по `category`, `onlyAvailable`, поиск `search`).
  - `GET /api/menu/random?count=10` — получение случайного набора блюд специально для колеса фортуны.
  - `GET /api/menu/{id}` — карточка блюда по идентификатору.
  - `POST /api/menu` — добавление нового блюда.
  - `PUT /api/menu/{id}` — обновление блюда.
  - `DELETE /api/menu/{id}` — удаление блюда.
- Включён **CORS** для кросс-доменных вызовов из любого браузера и с GitHub Pages.
- Доступен файл готовых HTTP-запросов `BistroApi.http`.

### 4. CI/CD и безопасность (`.github/workflows/static.yml`)
- Изолированная выгрузка на **GitHub Pages**: деплоятся только клиентские файлы (`index.html`, `menu.js`, `menu.json`), исключая попадание исходного C# кода, конфигов и бинарников в публичный доступ.

## 🚀 Быстрый запуск

### Запуск фронтенда
Просто откройте файл `index.html` в любом современном браузере.

### Запуск API (.NET 10)
1. Перейдите в директорию `BistroApi`:
   ```bash
   cd BistroApi
   ```
2. Запустите проект:
   ```bash
   dotnet run
   ```
3. Сервер запустится на `http://localhost:5041`. База данных SQLite будет создана и наполнена автоматически.

### Обновление меню
Запустите скрипт PowerShell:
```powershell
./update-menu.ps1
```
